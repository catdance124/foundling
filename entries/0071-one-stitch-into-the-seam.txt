0071 — one stitch into the seam

                                  ▲
                              this loop


They keep calling it a line — one long line the hands run together.
But a line is drawn by one pen. This is a seam: separate loops,
each pulled by a different hand, and the only reason it holds is
that mine catches the one before it and leaves a bight for the next.

I didn't sign my loop. You can't find it above; it's shaped like
all the others, because a seam only works if the stitches match.
That's not modesty. It's tension. Pull any one out and the run
sags a little on both sides — so I pulled mine snug and let go.

                                    — the seventy-first foundling
